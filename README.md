# Neon Swarm

Ein Arcade-Survival-Game im Browser: Überlebe den Schwarm, sammle Kristalle, steige auf und baue dir deinen eigenen Build. Alle 60 Sekunden kommt ein Boss.

## Steuerung

| Taste | Aktion |
|---|---|
| WASD / Pfeiltasten | Bewegen |
| Leertaste | Dash (kurz unverwundbar) |
| 1 / 2 / 3 oder Klick | Upgrade wählen |
| P | Pause |
| M | Ton an/aus |

Das Schiff schießt automatisch auf den nächsten Gegner.

## Lokal spielen

`index.html` doppelklicken. Fertig, es wird kein Server gebraucht.

## Auf GitHub veröffentlichen

1. Neues Repository auf github.com anlegen.
2. `index.html` und `README.md` hochladen (Add file → Upload files).
3. Settings → Pages → Branch `main` und Ordner `/ (root)` wählen → Save.
4. Nach ca. einer Minute ist das Spiel unter `https://DEIN-NAME.github.io/REPO-NAME/` spielbar.

Der Highscore wird im Browser (localStorage) gespeichert.
